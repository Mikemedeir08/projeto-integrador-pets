# Sistema de Gestão de Pets e Adoção - Projeto Integrador

Projeto desenvolvido para a disciplina de Projeto Integrador / Extensão Universitária.

Objetivo: Sistema web simples para gestão de cadastros de pets resgatados e controle de adotantes para ONGs comunitárias.

Estrutura:
- /docs: Documentos de requisitos e arquitetura
- /database: Scripts do banco de dados
- /src: Código-fonte do sistema
