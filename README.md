Laços Caninos 🐾
Sistema web completo desenvolvido para a gestão operacional de resgates, controle de saúde e adoção responsável de animais em abrigos parceiros.

🚀 O que o sistema faz
Cadastro de Pets: Registo detalhado de animais resgatados, incluindo raça, porte e histórico completo de vacinação/procedimentos com datas e observações de saúde.

Gestão de Adotantes: Registo de pessoas interessadas na adoção, armazenando contactos e endereços completos.

Painel de Controle do Abrigo: Indicadores em tempo real de animais disponíveis, adotados e total de interessados.

Vínculo de Adoção: Associação direta entre o adotante e o pet resgatado, permitindo visualizar de forma explícita quem adotou quem.

Persistência e Controlo: Capacidade de gerir os dados com listagens dinâmicas e exclusão de registos.

🛠️ Tecnologias Utilizadas
HTML5

CSS3

Bootstrap 5 (Framework para estilização e responsividade)

JavaScript (Lógica de manipulação de estados, rotas SPA e persistência local)

💻 Como rodar o projeto
Pré-requisitos:

Ter qualquer navegador web moderno instalado (Google Chrome, Microsoft Edge, Firefox, etc.).

Passo a passo:

Faça o download ou clone este repositório para o seu computador.

Certifique-se de que a estrutura de pastas está correta (index.html na raiz, pasta css/ e pasta js/).

Dê um duplo clique no arquivo index.html para abrir o sistema diretamente no seu navegador.
